# Cron 最小冒烟清单（statistics Facade 路径）

更新时间：2025-10-02

目标：验证 `CronService` 改造后使用 `StatisticsFacadeService` 的路径在运行期无异常。

## 预置条件
- `.env` 配置 Redis（可选），若无 Redis，确保微服务启动逻辑能容忍无密码连接或改用本地默认。
- 数据库可连通，存在基础数据（可复用 seed 数据）。

## 步骤
1) 构建与启动
- 执行构建并启动（dev 模式即可）。
- 观察应用与 Redis 微服务启动日志，无未捕获异常。

2) 触发每日统计
- 方式 A：等待定时任务触发（若有 schedule）；
- 方式 B：提供临时触发端点或在 `CronService` 内手动调用 Facade 方法进行一次性触发（仅本地）。

3) 校验
- 查看日志中 Facade 方法执行结果；
- 若有缓存清理步骤，验证 `RedisService.clearPattern` 的调用未报错；
- 如有统计数据落库或缓存，抽样查询验证格式与数量级合理。

## 通过标准
- 应用无错误日志；
- 日志显示统计函数返回结构正常；
- 前端依赖的统计接口可正常读取（如有）。
